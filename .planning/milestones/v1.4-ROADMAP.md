## Overview

v1.4 closes the v1.2/v1.3 deferred live-validation gates against the real servers
(`mail.utfpr.edu.br` / `smtp.utfpr.edu.br:587`) using user-provided credentials
(git-ignored `src-tauri/.live-test.env`, never committed), under a strict sandbox
safety contract — and adds final capabilities: SQLite full-text search with saved
filters, age-based auto-archive reusing the batch machinery, and user-defined smart
folder rules with conflict confirmation.

**Sandbox safety contract (structural, all live phases):** dedicated
`SGE-Test-<run-id>` folder per run; ALL mutating ops scoped to it; mail sent ONLY
to the user's own address; existing mail/folders never touched; pre-flight guard
aborts on out-of-sandbox targets; run ends with full cleanup. Offline doubles
(MockSession/FakeSession, record-replay SMTP) stay as CI fallback.

Live execution of all three live gates (LIVE-01/02/03) is **deferred with reason**:
`src-tauri/.live-test.env` never existed in this environment, so no authenticated
operation was performed by any phase. Each gate ships a fully implemented runner
with an exit-2 SKIP contract verified without creds (standing `user_setup`,
same pattern as v1.3).

**Environment caveat:** `vite` bundle (`npm run build`) fails environmentally —
Node v18.19.1 vs rolldown-vite requiring `node:util` styleText (Node 20.12+).
Fails at vite startup before any project code loads; NOT a phase failure.
`tsc --noEmit` is the UI gate and is clean. Retry `npm run build` on a Node 20+ host.

# Plan 05-01 — Auto-connect on Launch

## What

Add a `load_server_config()` Tauri command (exposes existing KeyringStore method)
and update `App.tsx` to auto-connect on mount when saved credentials exist.

## Steps

1. Add `load_server_config()` Tauri command in `lib.rs` (spawn_blocking → KeyringStore::load_server_config)
2. Register in `invoke_handler`
3. Update `App.tsx`:
   - Add `autoConnecting` state
   - On mount useEffect: `load_credentials` → if exists, `load_server_config` → `connect_account` → `start_sync` → setConnected(true)
   - If credentials missing or keyring unavailable → show LoginForm (existing flow)
   - While auto-connecting → show "Connecting…" message instead of LoginForm
4. The `SavedCredentials` + `ServerConfig` TypeScript interfaces already exist in LoginForm.tsx

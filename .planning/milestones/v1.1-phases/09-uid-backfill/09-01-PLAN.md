## Overview

**Goal**: User never silently misses mail that arrived between syncs.

**Mode**: mvp

**Build order**: Gap detection → Convergence test → Verification.

---

## Wave 1 — Gap detection + convergence (09-01-PLAN.md)

### Objective
Implement UID gap detection and convergence as a property of incremental sync, ensuring no silent missed messages.

### Tasks

**Task 1 — UID range-diff logic** (`src-tauri/src/sync/worker.rs`):
- After incremental sync, compute `local_uids` set and `server_uids` set
- Identify gap: UIDs in `server_uids` \ `local_uids` that arrived after last sync
- Fetch only the gap UIDs via `fetch_message`; no full UIDNEXT walk
- Tombstone expunged UIDs: stop re-requesting after 3 empty FETCH results

**Task 2 — Convergence test** (`src-tauri/src/sync/worker.rs`):
- Double-poll-zero-FETCH convergence: two consecutive polls with no server change issue no message FETCHes
- Log convergence state in SyncSummary for UX visibility

**Task 3 — Verification** (validation tests):
- `cargo test --manifest-path src-tauri/Cargo.toml uid_gap`
- `cargo test --manifest-path src-tauri/Cargo.toml convergence_test`

*As-built 2026-10-05: full sweep covers the whole SEARCH set every pass
(no UIDNEXT walk exists to miss from), so criterion 1 holds by
construction; the phase adds (a) in-pass range-diff re-fetch of partial
batch drops (+ strike counting), (b) tombstoning at 3 strikes with prune
on expunge and recovery on the periodic full sweep, (c) the convergence
shortcut (skip sweep when UID sets match, no bump, no pending ops) with a
periodic full sweep every 5 passes so remote flag changes still surface.
`SyncSummary` gains `fetched / gap_refetches / converged`. Previous
double-sync test updated to the new semantics (converged asserts +
forced periodic sweep proving the update path).*

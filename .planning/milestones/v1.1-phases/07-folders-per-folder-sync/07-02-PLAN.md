## Overview

**Goal**: Expose multi-folder sync to the Tauri command layer with per-folder STATUS caching.

**Mode**: mvp

---

## Wave 2 — Commands + DB Migration (07-02-PLAN.md)

### Objective
Expose multi-folder sync to the Tauri command layer with per-folder STATUS caching.

### Tasks

**Task 1 — DB Migration M3** (`src-tauri/src/store/mod.rs`):
- Add `unseen_count INTEGER DEFAULT 0` column to `mailboxes` table via M3 migration
- Update `SCHEMA_VERSION` to 3
- Write migration test: `m3_adds_unseen_count_column`

**Task 2 — Query functions** (`src-tauri/src/store/queries.rs`):
- Add `list_mailboxes(conn) -> Vec<MailboxRow>` — returns all folders with unread counts
- Add `MailboxRow` struct: `MailboxRow { id: u64, name: String, uid_validity: u32, uid_next: u32, unseen_count: i64, last_sync_at: Option<String> }`
- Add `set_mailbox_status(conn, name, uid_validity, uid_next, unseen_count)` — upsert STATUS data
- Add `count_unread(conn, mailbox_id) -> i64` — count messages with flags not containing \Seen

**Task 3 — Tauri commands** (`src-tauri/src/commands/sync.rs`):
- Add `list_folders(state) -> Result<Vec<MailboxRow>, String>` — calls SessionManager.list_mailboxes + STATUS, caches in DB, returns rows
- Generalize `start_sync(state, mailbox: String, on_event)` — accept mailbox name, SELECT that folder
- Generalize `sync_status(state, mailbox: String)` — look up sync state for the named mailbox
- Generalize `list_messages(state, mailbox: String, offset, limit)` — filter by named mailbox
- Generalize `fetch_message(state, uid, mailbox: String)` — SELECT the named mailbox before fetch

### Verification
```

```

## Wave 3 — Frontend folder tree (07-03-PLAN.md)

### Objective
Frontend folder tree and per-folder browsing UI.

### Tasks

**Task 1 — Types** (`src/types.ts`):
- Add `MailboxRow` type reflecting the DB row
- Add `FolderSelectEvent` type for mailbox selection change

**Task 2 — Sidebar** (`src/components/Sidebar.tsx`):
- Replace hardcoded fake entries with `LIST`-discovered folder tree
- Add `mailbox` state managed by context/provider
- Render folder icons with unread badges from `unseen_count`

**Task 3 — MailboxView** (`src/components/MailboxView.tsx`):
- Accept `mailbox` prop
- Render message list for the selected folder (headers-first, same as INBOX)
- Show empty/loading/error states per folder

**Task 4 — App.tsx**:
- Wire mailbox selector to `SessionManager.select_mailbox()`
- Pass `mailbox` prop through component tree
- Preserve INBOX-only fallback when no folder selected

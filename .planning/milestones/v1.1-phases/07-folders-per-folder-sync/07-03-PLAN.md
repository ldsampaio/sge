## Wave 3 — Frontend folder tree (07-03-PLAN.md)

### Objective
Frontend folder tree and per-folder browsing UI.

### Tasks

**Task 1 — Types** (`src/types.ts`):
- Add `MailboxRow` type reflecting the DB row
- Add `FolderSelectEvent` type for mailbox selection change

**Task 2 — Sidebar** (`src/components/Sidebar.tsx`):
- Replace hardcoded fake entries with `LIST`-discovered folder tree
- Add `mailbox` state managed by context/provider
- Render folder icons with unread badges from `unseen_count`

**Task 3 — MailboxView** (`src/components/MailboxView.tsx`):
- Accept `mailbox` prop
- Render message list for the selected folder (headers-first, same as INBOX)
- Show empty/loading/error states per folder

**Task 4 — App.tsx**:
- Wire mailbox selector to `SessionManager.select_mailbox()`
- Pass `mailbox` prop through component tree
- Preserve INBOX-only fallback when no folder selected

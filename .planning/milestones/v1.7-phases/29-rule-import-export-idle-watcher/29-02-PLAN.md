Create IdleWatcher in imap/idle.rs (per CONTEXT.md D-04, D-05, D-06, D-07):
- Struct: IdleWatcher { account_id, config: AccountConfig, sync_wake: SyncWake, state: IdleState, handle: Option<JoinHandle<()>> }
- IdleState enum: Connecting, Selecting, Idling, Done, Reconnecting(backoff_attempt), Stopped
- run() loop:
  1. Connect via SessionManager::connect_sync(config.clone()) → dedicated session
  2. SELECT INBOX (read-only)
  3. session.idle() → Handle
  4. Loop: handle.wait() → on EXISTS/RECENT → SyncWake::request_sync(account_id) (advisory, coalesced)
  5. On any exit (handle.done(), error, timeout, Cancelled): send DONE via session.run_command("DONE") if possible, then LOGOUT
  6. Backoff: exponential with jitter, capped at manager's max (reuse SessionManager backoff config), max 29 min before re-IDLE
  7. Capability gate: check capability-profile.json IDLE atom at spawn; if false → never spawn, return IdleStatus::Unavailable
- Spawn: SyncWorker::start() reads capability, spawns IdleWatcher if IDLE=true, stores handle in SyncWorker
- Commands: idle_status(account_id) → IdleStatus { state: Push|Polling|Offline|Unavailable, last_wakeup: Option<DateTime>, reconnect_attempt: u32 }
- Register idle_status in commands/sync.rs
- Expose IdleWatcherHandle in imap/mod.rs for test injection (MockIdleWatcher)

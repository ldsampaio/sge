# Plan 10-01: Transport — SyncSession delete/move verbs + MockSession arms

## Overview

- **Goal:** `SyncSession` trait gains UID-only delete/move verbs (`store_deleted`, `uid_expunge`, `expunge`, `uid_copy_to`, `uid_move_to`, `capabilities`, `create_mailbox`) with `BoxedSession` impls and `MockSession` arms, so manager/replay/commands have a tested transport to build on. No store, command, or UI changes.
- **Mode:** mvp
- **Deps:** Phase 9 complete. No intra-phase deps (first wave).
- **Requirements:** DEL-01, DEL-02, MOVE-01 (transport slice only; no user-visible behavior yet).

## Wave 1: Trait + impl + mock + unit gates

Objective: verbs exist on trait, work on real session shape, and are fully covered by MockSession-driven unit tests including the capability fallback matrix inputs.

### Tasks

1. **`src-tauri/src/imap/mod.rs` — trait additions**
   - Add to `SyncSession` trait (after `set_seen`, ~line 304-307), all `PinBox` object-safe:
     - `fn store_deleted(&mut self, uid: u32, deleted: bool) -> PinBox<'_, Result<(), SyncError>>`
     - `fn expunge(&mut self) -> PinBox<'_, Result<Vec<u32>, SyncError>>`
     - `fn uid_expunge(&mut self, uid_set: &str) -> PinBox<'_, Result<Vec<u32>, SyncError>>`
     - `fn uid_copy_to(&mut self, uid_set: &str, dest: &str) -> PinBox<'_, Result<(), SyncError>>`
     - `fn uid_move_to(&mut self, uid_set: &str, dest: &str) -> PinBox<'_, Result<(), SyncError>>`
     - `fn capabilities(&mut self) -> PinBox<'_, Result<Vec<String>, SyncError>>` (return owned `Vec<String>` of capability atoms — object-safe, no lifetime leak from vendored `Capabilities` struct)
     - `fn create_mailbox(&mut self, name: &str) -> PinBox<'_, Result<(), SyncError>>`
   - Add helper `pub fn deleted_store_arg(deleted: bool) -> &'static str` mirroring `seen_store_arg` (337-343): `"+FLAGS.SILENT (\\Deleted)"` / `"-FLAGS.SILENT (\\Deleted)"`.
   - Verify: `cargo test -p sge imap::` compiles; `cargo clippy --all-targets` clean.

2. **`src-tauri/src/imap/mod.rs` — `BoxedSession` impls (copy `set_seen` template 435-450 verbatim)**
   - `store_deleted`: `uid_store(uid.to_string(), deleted_store_arg(deleted))`, drain stream with `try_collect::<Vec<_>>()`, map errors `SyncError::Protocol("UID STORE Deleted uid {uid}: {e}")`.
   - `expunge`: `self.expunge()` → collect seq numbers, drain to completion, `SyncError::Protocol("EXPUNGE: {e}")`. Collect-and-drop (never trust seq as UID).
   - `uid_expunge`: `self.uid_expunge(uid_set)` → collect, same error shape `"UID EXPUNGE {set}: {e}"`.
   - `uid_copy_to`: `self.uid_copy(uid_set, dest)` → `Result<()>`, error `"UID COPY {set} -> {dest}: {e}"`. Pass raw wire names (no display_name).
   - `uid_move_to`: `self.uid_mv(uid_set, dest)` (exact vendored name — NOT `move`), error `"UID MOVE {set} -> {dest}: {e}"`.
   - `capabilities`: `self.capabilities()` → map to `Vec<String>` via atom names; error `"CAPABILITY: {e}"`.
   - `create_mailbox`: `self.create(name)` → error `"CREATE {name}: {e}"`.
   - Rule: NO parsing of untagged `COPYUID`/`APPENDUID`/extended responses (imap-proto 0.16 tripwire class, RESEARCH §1).
   - Verify: `cargo test -p sge imap::` green.

3. **`src-tauri/src/sync/worker.rs` — `MockSession` arms (623-715)**
   - Add recorded-call vecs: `deleted_calls: Vec<(u32,bool)>`, `copied_calls: Vec<(String,String)>`, `moved_calls: Vec<(String,String)>`, `expunged_sets: Vec<String>`, `plain_expunge_calls: usize`, `created_mailboxes: Vec<String>`.
   - Add `fail_*` toggles: `fail_deleted`, `fail_expunge`, `fail_copy`, `fail_move`, `fail_create`.
   - Add `canned_capabilities: Vec<String>` (default `["IMAP4rev1","UIDPLUS","MOVE"]`); `capabilities()` returns it.
   - `select_mailbox` call recording must exist or be added (`select_calls: Vec<String>`) — needed by Plan 10-02 lease-hold test.
   - Verify: `cargo test -p sge sync::worker::` green.

4. **Unit tests (new, in `mod.rs` / `worker.rs` test modules)**
   - `deleted_store_arg` spelling/purity test (mirror T-6-01 `seen_store_arg` test 660-677).
   - `store_deleted` UID-addressing record test on MockSession: UID reaches wire, no seq-number API used.
   - Capability-matrix verb-selection pure test (helper `choose_move_path(caps) -> MovePath::{UidMove,FallbackCopy}` and `choose_expunge_path(caps) -> ExpungePath::{UidExpunge,UnmarkDance,Refuse}`): MOVE+UIDPLUS / neither / mixed combos assert correct branch enum. (Branch execution itself is Plan 10-02.)
   - UID-set chunking test: 450 UIDs → 3 chunks of ≤200, comma-joined `"1,2,3"` shape.
   - Verify: `cargo test -p sge` fully green (Phase 6-9 suites must stay green).

## <threat_model>

- **Scope:** ASVS L1. New verbs are transport-only; no command/UI calls them yet, so no user-reachable destruction in this plan.
- **Hazards:**
  - *Wrong-verb wiring (seq `store` instead of `uid_store`):* mitigated by UID-addressing record test + clippy; reviewer checks no `store(`/`copy(`/`mv(` seq variants appear.
  - *Dropped-stream abort (STORE silently never completes):* every impl drains with `try_collect`; test asserts mock stream fully consumed.
  - *Untagged-response parse poisoning (NAMESPACE tripwire class):* this plan adds NO response-code parsing; any future COPYUID parsing needs a replay-stream regression test — noted as explicit non-goal.
  - *Bare `expunge()` exposure:* trait exposes it but no caller exists until Plan 10-02's gated fallback; `uid_expunge` is documented as the default.
- **Block on high:** any test showing a verb addressing by sequence number, or any added parsing of untagged extended responses without a tripwire test → block.
</threat_model>

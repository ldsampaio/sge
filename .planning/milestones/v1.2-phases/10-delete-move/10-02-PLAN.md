# Plan 10-02: Manager leases + start_sync precondition + Trash detect

## Overview

- **Goal:** Lease-scoped destructive methods on `SessionManager` with reconnect-retry and capability-gated MOVE/expunge fallback orchestration (single lease held, no re-entrancy), `start_sync` routed under manager leases, and Trash auto-detect helper — before any command ships.
- **Mode:** mvp
- **Deps:** 10-01 (verbs + MockSession arms + `select_calls` recording).
- **Requirements:** DEL-01, DEL-02, MOVE-01 (backend slice; user-visible in 10-03/10-04).

## Wave 1: Manager lease methods + fallback orchestration

Objective: `SessionManager` owns all destructive IMAP traffic under one held lease per op.

### Tasks

1. **`src-tauri/src/imap/manager.rs` — capability cache**
   - Extend `ManagerState` (lines 32-36) with `cached_capabilities: Option<Vec<String>>`; query `capabilities()` once per fresh connection in `lease_for`, invalidate on `reconnect()` (95-103).
   - Add `pub async fn capabilities_cached(&self) -> Result<Vec<String>, SyncError>` helper.
   - Verify: `cargo test -p sge imap::manager::` green.

2. **`src-tauri/src/imap/manager.rs` — simple lease methods (copy `set_seen_in` 111-128 verbatim)**
   - `mark_deleted_in(mailbox, uid, deleted)`: `lease_for` → `store_deleted` → drop+`reconnect`+retry exactly once.
   - `uid_expunge_in(mailbox, uid_set)`: same shape around `uid_expunge`.
   - `create_trash()`: `lease_for("INBOX")` (any selected folder suffices for CREATE) → `create_mailbox("Trash")` + retry-once. Raw ASCII name, no mutf7.
   - Verify: `cargo test -p sge imap::manager::` green.

3. **`src-tauri/src/imap/manager.rs` — `move_message_in` (lease-hold critical)**
   - Signature: `pub async fn move_message_in(&self, src: &str, uid_set: &str, dest: &str) -> Result<MoveOutcome, SyncError>` with `MoveOutcome { used_fallback: bool }`.
   - Hold ONE `lease_for(src)` guard for the whole sequence; drive verbs via `lease.session().uid_move_to / uid_copy_to / store_deleted / uid_expunge` directly. NEVER call `self.lease_for()` re-entrantly while holding a lease (async mutex → deadlock).
   - Branch on cached caps: MOVE → single `uid_move_to`; else `uid_copy_to` → `store_deleted(+Deleted per uid — chunk uid_set)` → UIDPLUS `uid_expunge(set)` else unmark-dance fallback: SEARCH live `\Deleted` UIDs not in our set → `-FLAGS` them → plain `expunge()` → restore `+FLAGS`; if unmark can't be verified → return `SyncError::Protocol` plain-language refusal ("servidor não suporta UID EXPUNGE…"), never blind expunge.
   - Reconnect-retry: on first failure drop lease, `reconnect()`, fresh `lease_for(src)`, retry whole sequence once (re-read caps after reconnect).
   - Chunk `uid_set` at ~200 UIDs per verb call (match `BATCH_SIZE`).
   - Verify: `cargo test -p sge move_fallback` — MockSession cap combos (MOVE+UIDPLUS / neither / mixed) assert verb sequences in `moved_calls` vs `copied_calls+deleted_calls+expunged_sets`.

4. **`src-tauri/src/imap/manager.rs` — regression tests**
   - Lease-hold test: fallback COPY+STORE+EXPUNGE issues exactly ONE `select_calls` entry (no intermediate SELECT).
   - No-reentrancy test: `move_message_in` while a lease is held never deadlocks (timeout-guarded test asserting completion).
   - Multi-client survival test: foreign `\Deleted` UIDs (mock pre-marked, not in our set) survive `uid_expunge`; plain-expunge fallback asserts `-FLAGS` unmark + restore calls for foreign UIDs.
   - Verify: `cargo test -p sge imap::manager::` green.

## Wave 2: start_sync under manager leases (precondition)

Objective: no fresh-session-per-sync competing with destructive leases.

### Tasks

1. **`src-tauri/src/commands/sync.rs` — route `start_sync` through `manager_for().lease_for()`**
   - Replace `connect_sync(&account_cfg)` at line 131 with `lease = manager.lease_for(&mailbox)`; pass `lease.session()` as `&mut dyn SyncSession` into refactored `sync_with_session`. Keep `spawn_blocking`+`block_on` discipline (117-118) and `SyncGate::try_begin` single-flight.
   - `connect_sync` stays for `imap_probe`/bootstrap only — add `#[allow(dead_code)]` or doc note, do not delete.
   - Single-flight contention test: lease + sync serialize with no second connection (assert via manager session identity / `connect_sync` call count == 1 across concurrent `start_sync` + `mark_deleted_in`).
   - Verify: `cargo test -p sge` full suite green (Phase 6-9 + Wave 1 tests).

2. **Trash auto-detect helper (`src-tauri/src/commands/sync.rs` or new `src-tauri/src/imap/trash.rs`)**
   - `pub fn detect_trash(mailboxes: &[MailboxInfo]) -> TrashResolution { Found(String) | Missing }`: layer 1 SPECIAL-USE `\Trash` via existing `name_attribute_to_string` mapping; layer 2 case-insensitive name match (`trash`, `deleted`, `deleted items`, `lixeira`, `papelera`, `[gmail]/trash`, `[gmail]/lixeira`) reusing `SYSTEM_ORDER` rank list from Sidebar; layer 3 = `Missing` (caller prompts confirm → `create_trash()`).

   - Unit tests: attribute wins over name; PT `Lixeira` match; missing → `Missing`.
   - Verify: `cargo test -p sge trash` green + `tsc --noEmit` untouched (no frontend changes this plan).

## <threat_model>

- **Scope:** ASVS L1. First plan where server-side destruction is reachable in code (still no UI caller).
- **Hazards:**
  - *Wrong-folder EXPUNGE (double-SELECT drift):* mitigated by single-lease-hold rule + one-SELECT assertion test; reviewer rejects any `lease_for` call inside a held-lease scope.
  - *Lease deadlock (re-entrant `lease_for` on async mutex):* mitigated by no-reentrancy test with timeout; block on any new `self.lease_for` inside `move_message_in`/`uid_expunge_in`.
  - *Other clients' `\Deleted` nuked by plain `expunge()`:* mitigated by unmark-dance + fail-loud refusal when unverifiable; multi-client survival test is the gate.
  - *Stale-UID delete after UIDVALIDITY change:* replay gating lands in 10-03, but manager methods take caller-supplied uid_sets only — commands (10-03) own epoch checks; noted as residual until then.
  - *Second-connection race (sync sweep vs lease EXPUNGE):* mitigated by start_sync-under-lease + no-second-connection assertion test.
- **Block on high:** intermediate SELECT in fallback sequence, blind plain-`expunge()` without verified unmark dance, or deadlock-timeout failure → block.
</threat_model>

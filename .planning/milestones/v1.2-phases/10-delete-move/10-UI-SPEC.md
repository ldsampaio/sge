## Spacing Scale

Declared values (must be multiples of 4). Source: existing `--space-*` tokens in `src/styles/tokens.css` (pre-populated, not re-asked):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`--space-1`) |
| sm | 8px | Compact element spacing (`--space-2`) |
| md | 16px | Default element spacing (`--space-4`) |
| md+ | 20px | Reader padding steps (`--space-5`) |
| lg | 24px | Section padding (`--space-6`) |
| xl | 32px | Layout gaps (`--space-8`) |
| 2xl | 40px | Major section breaks (`--space-10`) |

Exceptions: `--space-3: 12px` exists in tokens.css and may be used for row-internal and menu-item padding only. Modal content padding is 20px (`--space-5`); modal-to-backdrop margin is minimum 16px (`--space-4`). Toast bottom offset is 16px (`--space-4`). No 44px touch-target exception — row action buttons are 30px icon targets inside full-width rows; the modal confirm/cancel buttons are full-height pill buttons (existing `.btn` shape).

## Color

Source: `src/styles/tokens.css` semantic layer (pre-populated from codebase):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f4f5fd` (`--color-background`) | App background, pane surfaces |
| Secondary (30%) | `#ffffff` (`--color-card`) | Cards, message rows, sidebar, reader pane, move-menu surface, modal surface |
| Accent (10%) | `#4f46e5` (`--color-primary`, indigo-600) | Interactive emphasis only (see reserved list) |
| Destructive | `#dc2626` (`--color-destructive`) | Destructive actions only — ACTIVE in this phase: expunge confirm button, Trash-state row treatment, delete icon hover |

Accent reserved for: unread dot (amber `#ea580c` stays for the dot itself — see note), active/selected message row outline, primary "Buscar mensagens" button, pending-sync row marker, move-menu selected destination highlight, focus ring (`--color-ring`). Never for body text or decorative illustration.

Destructive reserved for (exhaustive list for this phase):
1. Expunge-modal confirm button (solid `#dc2626` bg, white text, 3px border darker — same clay pill shape as SyncStatus button)
2. Delete icon-button hover state (red icon + red 2.5px row-border tint on the button only, never the whole row)
3. Expunge-modal title icon (trash glyph in destructive color)
4. Empty-Trash affordance in the Trash folder header (text button in destructive color)

Notes:
- Unread-dot color stays amber `#ea580c` (`--badge-unread-bg`) — existing triage signal, unchanged by this phase.
- Pending delete/move state reuses the Phase 06 `--color-accent-soft` `#ffedd5` row wash + aggregate "N alterações aguardando envio" in SyncStatus (locked established pattern: optimistic UI + pending wash + rollback-on-reject). No new pending color.
- Locally-moved-away rows do NOT linger: the row is removed from the source list optimistically (with undo via toast), never shown struck-through.
- Modal backdrop is `rgba(30, 27, 75, 0.45)` (primary-ink at 45%) — new value, recorded here; backdrop click does NOT confirm (cancel only via Esc / Cancelar button / backdrop click = cancel).
- Text: `--color-foreground` `#1e1b4b` on light surfaces; muted `--color-muted-foreground` `#475569`; borders `--color-border` `#c7d2fe`. All pairs hold WCAG AA per tokens.css header claim.
- Success confirmation (server-acknowledged move/delete) uses existing `--color-success` `#15803d` only in SyncStatus text, never as a row wash.

## Accessibility

| Requirement | Contract |
|-------------|----------|
| Row action buttons | Real `<button type="button">` elements with `aria-label` ("Apagar mensagem" / "Mover mensagem para…"); `stopPropagation` on click so row-select never fires; reachable by Tab in row order (dot → delete → move) |
| Move menu semantics | `role="menu"` with `role="menuitem"` items; `aria-label` "Escolher pasta de destino"; folder hierarchy exposed via nested `role="group"` + `aria-label` per parent (mirrors Sidebar `aria-label={shortLabel}`) |
| Move menu keyboard | Opens with focus on the first eligible destination; ArrowUp/Down moves, Enter selects, Esc closes and returns focus to the invoking button; focus is trapped inside while open |
| Undo toast semantics | `role="status"` (polite live region, never `alert`); "Desfazer" is a real button, keyboard-reachable; toast never auto-focuses on appear |
| Expunge modal semantics | `role="alertdialog"` + `aria-modal="true"` + `aria-labelledby` (title) + `aria-describedby` (body count text) |
| Expunge modal focus | Focus trap while open; initial focus on "Cancelar" (safe default, never the destructive button); Esc / backdrop click / "Cancelar" closes without action; focus returns to the invoking control on close |
| Destructive distinction | Destructive buttons never rely on color alone: trash glyph + explicit "para sempre" / "Não dá para desfazer" text accompany the red styling |
| Reduced motion | Toast slide-in and modal scale-in are disabled under `prefers-reduced-motion: reduce` (appear instantly; matches existing `.sync-progress` reduced-motion precedent) |
| Focus visibility | All new interactive elements use the existing `--color-ring` 4px focus ring (`0 0 0 4px rgba(79, 70, 229, 0.16)` + border-color primary, per `.search-bar-container:focus-within` precedent) |

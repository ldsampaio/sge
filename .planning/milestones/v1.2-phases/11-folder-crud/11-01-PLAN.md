# Plan 11-01: CREATE tracer — encode + manager + command + dialog + live gate

## Overview

- **Goal:** A user can create a folder end-to-end (type a name, pick a parent, see it appear selected in the sidebar) through a tested vertical slice: modified-UTF-7 encode → validation → manager CREATE → Tauri command → dialog + LIST refresh → live server gate with cleanup.
- **Mode:** mvp
- **Type:** tracer (first deliverable proves the whole folder-op path; Plans 11-02/11-03 widen it)
- **Deps:** Phase 10 complete (`create_mailbox` transport verb + `create_trash` lease pattern + `list_mailboxes` refresh + `ExpungeModal` skeleton). No intra-phase deps (first wave).
- **Requirements:** FOLD-04 (full vertical slice; RENAME/DELETE explicitly out of scope here).

## Wave 1: Tracer slice (transport → manager → command → UI → live server)

Objective: CREATE works against the real server through real UI, with encode/validation/manager covered by unit tests.

### Tasks

1. **`src-tauri/src/imap/mutf7.rs` — `encode_modified_utf7` + validation helper**
   - Add `pub fn encode_modified_utf7(name: &str) -> String`: ASCII printable (except `&`) passes through (delimiters `/`/`.` never encoded); `&` → `&-`; maximal non-ASCII runs → UTF-16BE → modified base64 (`,` for `/`, strip `=` padding) wrapped in `&…-`. Inverse grammar of `decode_modified_utf7` same file.
   - Add `pub fn validate_leaf(leaf: &str, delimiter: &str) -> Result<(), FolderNameError>` with `FolderNameError::{Empty, ContainsDelimiter(char), ReservedInbox}`; `ReservedInbox` on case-insensitive `inbox` match; empty-after-trim → `Empty`. Pure, no I/O.
   - Update the module doc comment claiming "encoding is never needed" — it is now needed; state the wire/display split.
   - Tests: roundtrip `decode(encode(x)) == x` for `Projetos`, `Lixeira & Cia`, `日本語`, `&-` literal, lone `&`; `&` never emits bare; delimiter bytes survive encode byte-identical; validation rejects `""`, `"  "`, `"A/B"` with `/`, `"inbox"`/`"INBOX"`/`"Inbox"`, accepts `"A&B"`.
   - Verify: <automated>`cargo test -p sge imap::mutf7::`</automated>
   - <fails_when>non-zero exit, or any `encode`/`validate` test FAILED in the output</fails_when>

2. **`src-tauri/src/imap/manager.rs` — `create_mailbox_in`**
   - Copy `create_trash` (225-237) verbatim shape: `lease_for("INBOX")` (CREATE needs no SELECT), `lease.session().create_mailbox(wire).await`, one reconnect-retry with the same `eprintln!` log shape. Takes the RAW wire name (already encoded by the caller) — never encodes inside.
   - Extend the `FakeSession` stub (`create_mailbox` arm ~772): record `created_mailboxes: Vec<String>` (exists) + add `fail_create: bool` toggle returning `SyncError::Protocol("fake create failure")`.
   - Tests: wire name reaches the verb byte-identical (`"Pai/Filho"` raw, `"Lixeira & Cia"` encoded form); retry succeeds after one `fail_create` then toggle off; `Refused`-shaped errors are NOT retried (no new lease attempt — assert `created_mailboxes.len() == 1`).
   - Verify: <automated>`cargo test -p sge imap::manager::`</automated>
   - <fails_when>non-zero exit, or `test result: FAILED` in the summary line</fails_when>

3. **`src-tauri/src/commands/sync.rs` + `lib.rs` — `create_folder` command**
   - Skeleton per `set_seen` (179-276): `pub async fn create_folder(leaf: String, parent: Option<String>) -> Result<FolderTreeResult, String>` where `parent` raw wire name or None = top level. `load_account_config` → `manager_for` → `spawn_blocking`+`block_on`; lock never across `.await`.
   - Order inside: (a) resolve delimiter: parent's cached delimiter via `list_mailboxes` row, else `""` for top level; (b) `validate_leaf` → map to UI-SPEC copy (`Dê um nome…`, `não pode conter…`, `INBOX é reservada…`); (c) join `parent + delim + leaf`, `encode_modified_utf7`, pre-check against cached tree (`Já existe…`); (d) `manager.create_mailbox_in(&wire).await` → map NO to plain language; (e) reuse the `list_mailboxes` refresh body verbatim (STATUS per folder, `\Noselect` skip, offline fallback) and return `{ created: wire, mailboxes: fresh_tree }`.
   - Online-only: on manager connect failure return `Sem conexão — pastas só podem ser alteradas online…` (UI-SPEC copy); NO outbox enqueue (no folder-op queue exists — explicit non-goal).
   - Register in `lib.rs generate_handler!` next to `delete_message` (line ~278).
   - Tests (`commands::` module, FakeSession-backed where the existing suite shows how): validation errors return before any verb call; existing-name short-circuits; offline manager error maps to the offline copy.
   - Verify: <automated>`cargo test -p sge commands::`</automated>
   - <fails_when>non-zero exit, or any `commands::` test FAILED</fails_when>

4. **`src/components/FolderDialog.tsx` (new) + `Sidebar.tsx` wiring + `MailboxView.tsx`**

## <threat_model>

- **Scope:** ASVS L1. First folder-mutation path; destruction radius is one new folder per op.
- **Hazards:**
  - T-11-01 *Wire-name confusion (display name sent to CREATE):* mitigated by raw-only rule — command takes wire parent + leaf and encodes itself; UI never encodes; test asserts byte-identical verb args. Block on high: any path passing `display_name` toward a verb.
  - T-11-02 *Hierarchy escape via delimiter in leaf (`a/b` creating nesting the user didn't pick):* mitigated by `validate_leaf` before encode + disabled confirm; test covers both `/` and `.` delimiters. Block on high: CREATE issued for an unvalidated leaf.
  - T-11-03 *INBOX-variant creation attempt:* mitigated by client-side `ReservedInbox` reject + server NO mapping; INBOX itself is never renamed/deleted by this plan (no such code path).
- **Block on high:** unvalidated leaf reaching `create_mailbox`, display-name on the wire, or offline silent queuing of a CREATE → block.
</threat_model>

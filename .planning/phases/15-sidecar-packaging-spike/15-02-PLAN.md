# Plan 15-02: Tauri wiring + Rust supervision (spawn / probe / kill)

**Goal:** App spawns the sidecar in `setup()`, health-probes it, restarts on crash, kills on exit. Wiring complete in `tauri.conf.json` + capabilities + Cargo.

**Tasks:**
1. Cargo: add `tauri-plugin-shell = "2"` and `reqwest = { version = "0.12", default-features = false }` (loopback plain-HTTP only; tokio via `tauri::async_runtime`). Verify `cargo check` green.
2. `tauri.conf.json`: `bundle.externalBin` ← `binaries/sge-laya-<triple>` (dev shim: build script copies frozen binary or a stub); `bundle.resources` ← weights dir mapping.
3. `capabilities/default.json`: `shell:allow-execute` scope pinned to sidecar binary + fixed argv prefix.
4. New module `src-tauri/src/sidecar.rs`:
   - `SidecarConfig { port, api_key }` — ephemeral loopback port picker + per-boot key (rand from OS; never logged).
   - `SidecarSupervisor`: `spawn()` (shell plugin Command, env `LAYA_HOST=127.0.0.1`, `LAYA_PORT`, `LAYA_API_KEY`, `LAYA_MAX_LOADED=1`), `health()` (GET /health with 2 s timeout + key header, maps to plain-language error), `ensure_running()` (restart with backoff, max 3 then `SidecarDown`), `shutdown()` (kill, no orphan).
   - Errors: `SidecarError` (thiserror) → plain language, key material never in Display.
5. `lib.rs`: `pub mod sidecar;` + `AppState.sidecar: Mutex<Option<Arc<SidecarSupervisor>>>`; `setup()` spawns backgrounded (never blocks window); `on_window_event Destroyed` / exit kills sidecar.
6. Unit tests: port picker loopback-only; per-boot key uniqueness + redaction (Display contains no key); supervisor state machine with mock child (spawn-fail → Down after retries); health-timeout mapping.
7. Tauri command `sidecar_status` → `{ running: bool, port: u16, cold_start_ms: Option<u64> }` (no key, no internal paths beyond binary name) for Phase 17 UI + tests.

**Verification:**
- `cargo test sidecar` green (≥6 tests); `cargo check` clean; no secret in logs (grep test).
- Dev run: app launches, sidecar child present, `/health` green via `sidecar_status`, quit leaves no orphan (pgrep check).
- `shell:allow-execute` scope rejects non-sidecar argv (capability test or documented manual check).

**Does NOT do:** classification calls, taxonomy, UI surfaces.

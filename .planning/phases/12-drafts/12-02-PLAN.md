# Plan 12-02: Server sync — save/discard sequence + commands + reconnect pass + live gate

## Overview

- **Goal:** Every draft save leaves exactly one server copy per compose session (APPEND-new + expunge-old), offline drafts flush on reconnect, and discarding removes both the row and the server copy — verified against fakes plus one live UTFPR round-trip with cleanup.
- **Mode:** mvp
- **Type:** vertical (transport → manager → command → worker; UI consumes it in 12-03)
- **Deps:** Plan 12-01 (drafts table + queries, renderer, `append_message`/`uid_search_header`, `DRAFT_FLAGS`, fake arms). Phase 10 (`mark_deleted`/`uid_expunge` single-UID path, pre-sweep replay discipline, `{ acked, pending_count, detail }` tone). Phase 11 (`create_folder` confirm-create flow for Missing Drafts).
- **Requirements:** DRAFT-02 (full: APPEND persist, expunge-old, reconnect flush). DRAFT-01 (server half of local-first: local write first, network second).

## Wave 2a: Manager sequence + commands + reconnect (parallel-safe with 12-03: disjoint files, frozen contract below)

Objective: `save_draft` / `get_draft` / `discard_draft` work online and offline; dirty rows flush on reconnect.

**Frozen UI contract (repeated verbatim in 12-03):** `invoke("save_draft", { id, subject, body, to, cc, bcc, mailbox? })` → `DraftSaveResult { id, dirty: bool, server_uid: number | null, acked: boolean, pending_count: number }`; `invoke("get_draft", { id })` → full row `{ id, subject, body, to, cc, bcc, dirty, server_uid, message_id }`; `invoke("discard_draft", { id })` → `{ id, discarded: true }`; missing-Drafts error string starts with `"drafts-missing"`; `mailbox` defaults to the roles-resolved Drafts wire name.

## <threat_model>

- **Scope:** ASVS L1. First path that APPENDs user-composed bytes to the server.
- **Hazards:**
  - T-12-03 *Duplicate server copies on retry (APPEND succeeded, reconcile SEARCH failed):* mitigated by stable `message_id` — the next save's SEARCH finds ≥2 and expunges down to the newest; live gate asserts count == 1 after re-save. Block on high: any save path that APPENDs with a fresh Message-ID.
  - T-12-04 *Expunge drift (old UID expunged from the wrong folder):* mitigated by single-lease SELECT of the Drafts wire for all legs. Block on high: expunge issued outside the drafts lease.
  - T-12-05 *Other-client mail destroyed:* scoped `UID EXPUNGE <old-uid>` only touches the tracked UID; plain `expunge()` never called on this path. Block on high: bare `expunge()` reachable from draft code.
- **Block on high:** fresh Message-ID per save, cross-folder expunge, or unscoped expunge on the draft path.
</threat_model>

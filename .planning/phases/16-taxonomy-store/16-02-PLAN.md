# Plan 16-02: M12 migration + classification store queries

**Goal:** `taxonomy`, `labels`, `label_overrides`, `classify_queue`,
`batch_runs` tables live behind migration M12 with query helpers and a
preserve-rows test.

**Tasks:**
1. `M12_CLASSIFY_SQL` const in `store/mod.rs` (same style as M2–M11) +
   register in production `apply_migrations` AND the test helper lists.
2. Schema:
   - `taxonomy(id TEXT PK, version INT, json TEXT, installed_at INT)`
   - `labels(message_id INT PK, primary_id TEXT, secondary_id TEXT NULL, confidence REAL, threshold REAL, stale INT DEFAULT 0)` — IDs only, never content
   - `label_overrides(id PK, message_id INT, from_id TEXT, to_id TEXT, at INT)` append-only
   - `classify_queue(id PK, message_id INT, folder TEXT, status TEXT, attempts INT DEFAULT 0, uidvalidity INT, enqueued_at INT)` + index (status, folder)
   - `batch_runs(id PK, started_at INT, finished_at INT NULL, state TEXT, totals_json TEXT DEFAULT '{}')`
3. `store/queries.rs`: install_taxonomy, get_taxonomy, upsert_label,
   get_label, mark_stale_by_version, log_override, enqueue_classify
   (idempotent per message+folder), dequeue_batch(limit), set_queue_state,
   create_batch_run, finish_batch_run.
4. Preserve-rows test: seed M11 db (messages + drafts + send_queue rows),
   migrate to M12, assert all prior rows intact + new tables empty.
5. Round-trip tests for every query (≥8).

**Verification:** `cargo test store` green incl. preserve-rows; no
regression in prior migration tests.
